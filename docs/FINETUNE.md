## Training data

- 680 candidate questions written by Gemini, each with a DuckDB query (`scripts/ft_generate.py`; it never reads the benchmark).
- 573 passed the second opinion: the question alone, sent through the exact eval prompt, gave the same result table (or, for unanswerable ones, a refusal).
- Removed for overlap with the 165 benchmark questions (`scripts/ft_filter.py`): 70 close in meaning (embedding similarity >= 0.85), 46 with the same answer as a benchmark question. Highest similarity left: 0.849.
- Kept 457 (29 unanswerable): 411 train, 46 validation.

## Training

- QLoRA with MLX on a MacBook Air M4 (16 GB): LoRA adapter on the 4-bit model, 152.8 minutes. Settings: `finetune/lora_config.yaml`.
- Checkpoint chosen by validation loss only (step 400, loss 0.105); the benchmark was run once, after that choice.

## Limits

- The benchmark questions are not yet reviewed by the owner (same caveat as the main results).
- The training questions come from Gemini, so this is distillation from a larger model, on one dataset.
- One run per model at temperature 0; no repeats for the local models.
